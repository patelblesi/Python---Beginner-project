🐍 Snake, Water, Gun Game

A simple command-line game built using Python, inspired by the classic Snake, Water, Gun game. Play against the computer and see who wins!

🎮 How to Play

Choose one of the following options:

* s — Snake 🐍
* w — Water 💧
* g — Gun 🔫

The computer randomly selects its choice, and the winner is determined according to the game rules.

🛠️ Technologies Used

* Python
* random module
* Conditional statements (if-elif-else)
* Dictionaries
* User input and output

🚀 How to Run

1. Clone this repository:

git clone YOUR-REPOSITORY-URL

2. Navigate to the project folder:

cd YOUR-PROJECT-FOLDER

3. Run the Python file:

python main.py

    Replace main.py with your actual Python filename if it is different.
